# r89-custom-ad

A lightweight **Vite + TypeScript** project to showcase **Refinery89’s new custom ad unit**.  
This repository serves as a demo website for testing, debugging, and presenting new ad formats.

---

## 🚀 Overview

The purpose of this project is to provide a fast and isolated environment to:

- Integrate and test **Refinery89 custom ad units**
- Analyze **layout behavior**, **viewability**, and **performance**
- Present ad format previews to **publishers and partners**

---

## 🧩 Tech Stack

- ⚡ [Vite](https://vitejs.dev/) – super fast dev environment  
- 🦾 [TypeScript](https://www.typescriptlang.org/) – for type-safe development  
- 💅 HTML + CSS – minimal, flexible styling  
- 🧱 Refinery89 Ad Tag – live ad integration
